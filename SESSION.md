### 🔴 Rule 6: World-Unit UV Box Meshes (Zero Texture Stretching & Proper Winding)
- Standard Unity `Cube` primitives scaled via `localScale` stretch standard `[0, 1]` UVs across long corridors and walls.
- All architectural geometry in `FlipFallLevelBuilder.cs` uses `GetOrCreateBoxMesh(Vector3 size, float uvScale = 0.5f)` with `transform.localScale = Vector3.one` and `BoxCollider.size = size`.
- Each quad face has UV coordinates calculated directly from world meters (`U = width * uvScale`, `V = height * uvScale`), guaranteeing 1 texture repetition per 2.0 physical meters across all elements regardless of length or height.
- **CRITICAL WINDING ORDER:** Quad triangulation MUST use clockwise winding `(0, 2, 1)` and `(0, 3, 2)` with `mesh.RecalculateNormals()` and `mesh.RecalculateTangents()`. Counter-clockwise winding causes front-face backface culling, making objects transparent from the front.
- Generated meshes are saved to the project asset `Assets/Meshes/LevelGeometryMeshes.asset`.
- Master Materials must maintain texture tiling scale and offset at `(1, 1)`.
